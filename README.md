# 🏆 بوت فانتسي الدوري الإنجليزي الذكي (FPL Smart Assistant Bot) ⚽

بوت تليجرام احترافي وشامل لمجتمع فانتسي البريميرليج، يعتمد على الـ API الرسمي المباشر للدوري الإنجليزي، ويوفر تحليلات تكتيكية، تقييم التشكيلة، ترشيحات الكابتن، وتتبع تغيرات الأسعار.

---

## 🌟 المميزات الرئيسية:

1. **🔍 فحص وتقييم التشكيلة (Rate My Team - RMT):**
   - يدخل اللاعب رقم الآيدي (Team ID) الخاص به فقط.
   - يسحب البوت تشكيلته الحالية الأساسية والاحتياطية.
   - يعطي تقرير بصحة التشكيلة من 100، كشف الغيابات والإصابات، المواجهات الصعبة (FDR 4+)، وأفضل تبديل مقترح.

2. **👑 ترشيحات الكابتن الذكية (Captain Decider):**
   - تحليل حسابي دقيق يجمع بين فورمة اللاعب، نسبة التهديف المتوقعة (xG)، سهولة دفاع الخصم، والأرض والجمهور.
   - ترتيب أفضل 5 خيارات كابتن للجولة القادمة مع مؤشر التألق.

3. **⚔️ مقارنة رأس برأس (Head-to-Head Compare):**
   - مقارنة سريعة بين أي لاعبين (مثال: `/vs Palmer Saka` أو `/vs بالمر ساكا`).
   - جدول يقارن السعر، النقاط، الفورمة، الأهداف، الأسيستات، ونسبة الملكية.

4. **📈 رادار تغير الأسعار (Price Watch):**
   - كشف يومي لأكثر اللاعبين طلباً (مرشحون للارتفاع) وأكثر اللاعبين بيعاً (مرشحون للهبوط).

5. **⏳ عد تنازلي للديدلاين (Deadline Timer):**
   - حساب دقيق للوقت المتبقي حتى إغلاق سوق الانتقالات بالساعات والدقائق بتوقيت مصر.

6. **🚀 ميزة الانتشار الفيروسي (Inline Sharing):**
   - يستطيع أي لاعب كتابة يوزر البوت في أي شات أو جروب (مثال: `@fpl_bot Haaland`) ليظهر له كارت إحصائيات اللاعب مباشرة ومشاركته مع أصدقائه!

7. **📢 لوحة تحكم المشرف والإعلانات (Broadcast Engine):**
   - إمكانية إرسال إعلانات ورسائل جماعية لجميع مستخدمي البوت بضغطة زر واحدة لتحقيق أرباح من الإعلانات.
